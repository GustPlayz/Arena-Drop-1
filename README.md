# ARENA DROP

Protótipo jogável de Battle Royale 3D para navegador, feito com HTML, CSS, JavaScript e Three.js.

## Como jogar
1. Extraia o ZIP.
2. Abra `index.html` em um navegador moderno com internet (Three.js é carregado por CDN).
3. Toque em **Entrar na partida**.

Em alguns celulares, abrir um HTML local pode bloquear módulos JavaScript. Nesse caso, publique a pasta em um host estático HTTPS, como GitHub Pages ou Netlify, e abra o endereço no navegador.

## Controles
- PC: WASD, mouse, clique para atirar, R recarregar, Espaço pular, Shift correr, C agachar.
- Celular: analógico esquerdo, arraste a área direita para girar a câmera e use os botões de ação.

## Escopo desta primeira versão
- Ilha procedural com casas, estradas, árvores e colisões simples.
- Jogador em terceira pessoa e 19 bots.
- IA básica de perseguição e disparos.
- Zona segura que diminui, vida, colete, armas alternáveis, munição, recarga e loot.
- HUD, contador de vivos, eliminações e condição de vitória/derrota.

É uma primeira versão funcional offline, não um serviço multiplayer. Os bots e o combate são simplificados; áudio dedicado, animações avançadas, minimapa real, inventário em grade e sincronização online ainda não fazem parte desta versão.
